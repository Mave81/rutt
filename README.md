# RUTT

Native förar-app (React Native) som loggar in mot Opter och hämtar dina jobb,
med ruttoptimering och lastplan. APK byggs automatiskt av GitHub Actions –
se fliken **Actions**, ladda ner artefakten **RUTT-debug-apk**.

Opter-protokollet (inloggning, synk, binäravkodning) är redan löst och flyttas in steg för steg.
